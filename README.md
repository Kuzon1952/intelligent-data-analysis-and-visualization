## Подготовка

Нужны Python 3.12 и [Poetry](https://python-poetry.org/docs/#installation).

```bash
git clone <адрес репозитория>
cd <папка репозитория>
poetry env use 3.12
poetry install
```

Затем скачайте данные с Яндекс Диска в папку `data/` — список файлов в [`data/README.md`](data/README.md).

Без Poetry можно так:

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows;  source .venv/bin/activate — Linux/macOS
pip install "pandas>=2.2,<3" pyarrow "taipy-gui>=4.1,<4.2" "plotly>=6,<7" "flask>=3.1.0,<3.1.3"
python task_1/app.py
```

## Структура

| Папка | Что внутри |
|---|---|
| `src/` | общий код: пути к данным, загрузка карточек, палитра, форматирование чисел по-русски |
| `docs/` | условия заданий и отчёт по исходным данным (`data_report.md`) |
| `data/` | данные курса (в Git не попадают, кроме CSV задания 3) |
| `task_1/` | задание 1: дашборд, тесты, `README.md`, `REPORT.md` |

## Как устроено каждое задание

- `app.py` — только интерфейс Taipy: разметка страницы, фильтры, обработчики;
- `metrics.py` — расчёты без Taipy и Plotly, поэтому их можно проверить тестами;
- `charts.py` — фигуры Plotly; `views.py` собирает плитки и графики для набора фильтров;
- `report.py` — собирает `REPORT.md` из тех же функций, поэтому числа в отчёте и на дашборде совпадают;
- `test_*.py` — проверки на синтетических данных: `poetry run python -m unittest discover -s task_1`.
