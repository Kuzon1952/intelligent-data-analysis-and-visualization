# Отчёт по исходным данным (задание 1)

Разбор набора `iavd_incidents_raw_target.parquet` перед построением дашборда: что в нём есть,
какие поля надёжны и какие решения из этого следуют. Числа получены на полном файле.

## Общая картина

| Показатель | Значение |
|---|---|
| Строк (карточек) | 240 295, `EntityId` уникален |
| Столбцов | 97 |
| Период по полю `Создан` | 12.04.2024 — 03.09.2025 (457 дат) |
| Время в файле | UTC; на дашборде переводится в московское |
| Источники | MaxPatrol SIEM — 142 549, Ankey SIEM NG — 97 551, прочие — 195 |
| Группа устранения | L1 — 98,6 %, L2 — 1,4 %, ГИБ — 44 карточки |

## Целевая переменная

Поле `Вердикт` (и его числовая копия `verdict`) — решение аналитика:

| Вердикт | Карточек | Доля | Группа на дашборде |
|---|---:|---:|---|
| False Positive | 150 675 | 62,7 % | Ложное срабатывание |
| Не указан | 54 870 | 22,8 % | Без вердикта |
| Решён | 28 606 | 11,9 % | Реальный инцидент |
| Дубликат | 5 819 | 2,4 % | Дубликат |
| Не решён, закрыт по совокупности, закрыт из родительской атаки | 325 | 0,1 % | Прочее |

Карточки без вердикта сосредоточены в июне — июле 2024 года, когда разметка только налаживалась.
Поэтому сравнивать доли вердиктов лучше с осени 2024 года.

## Качество полей времени

| Проблема | Масштаб | Решение |
|---|---|---|
| Нет `Дата взятия в работу` | 20,1 % карточек | закрыты, не попав к аналитику; в расчёт скорости взятия не входят |
| `Дата взятия в работу` раньше `Создан` | 33 036 карточек | ошибка выгрузки: интервал считается пропуском, а не нулём |
| Нет `Дата закрытия (факт)` | 17,5 % | в расчёт времени закрытия не входят |
| Закрытие раньше создания | 12 331 карточка | тоже пропуск |
| Нет флага `SLA просрочен (взятие в работу)` | 23,3 % | нарушение SLA считаем сами: время взятия > `SLA по взятию в работу Атаки` (мс) |

## Мультизначные поля

37 текстовых полей хранят несколько значений через разделитель `~~||~~` (например, `Тип инцидента`,
`Пиктограмма IRP`, `Источник инцидента`). Для разрезов на дашборде берётся первое значение;
карточки с несколькими источниками SIEM выделены в группу «Несколько SIEM».

## Почти пустые поля

11 полей заполнены меньше чем на 10 % (`Ошибки`, `Типы угроз`, `Прошлый ответственный`,
`Успех brute force`, `Эскалировался на L2?`, `False Positive` и др.) — на дашборде не используются.

## Учебная выборка

`iavd_1000_incidents_raw_target.parquet` — 1 000 карточек с 12.04.2024 по 06.05.2025; 79 % из них
без вердикта и только 5 реальных инцидентов. Дашборд на ней работает, но выводы делаются по полному набору.
